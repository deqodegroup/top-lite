# TOP Lite Design Direction

## Status
This file is the visual source of truth for TOP Lite.

TOP Lite uses an Apple-inspired design direction by deliberate product choice. This is not a universal DEQODE design rule and does not apply automatically to other products.

## Design intent
- Premium, calm, minimal and modern.
- White / near-white canvas with ocean-blue accents.
- Restrained liquid-glass surfaces, not excessive glass effects.
- Generous whitespace and clear visual hierarchy.
- STORM is the living visual centrepiece.
- Native-feeling mobile interactions.
- Minimal navigation.
- Subtle motion only where it improves presence or feedback.
- Accessibility and clarity take precedence over decorative effects.

## TOP Lite visual language
- Palette: luminous white, soft ice blue, deep ocean blue, restrained cyan highlights.
- Typography: clean system-first sans-serif with Apple-like restraint.
- Surfaces: translucent panels with subtle blur, fine borders and soft depth.
- STORM: central animated intelligence presence that reacts to idle, listening, thinking and speaking states.
- Composer: primary functional surface, inspired by conversational assistants rather than dashboard UI.
- Pacific influence: abstract, restrained and contemporary. Avoid literal decorative overload.

## Avoid
- Generic SaaS dashboards.
- Heavy card grids.
- Large marketing-landing-page hero copy.
- Neon or cyberpunk styling.
- Excessive gradients.
- Loud particle effects.
- Cluttered navigation.
- Decorative glass everywhere.
- Hard-coded visual assumptions that prevent future redesign.

## Design library note
The Apple-inspired direction is one option in the broader design library available to DEQODE products. TOP Lite currently selects this direction. Other projects may select other design systems or styles.

## Implementation rule
Before changing the TOP Lite interface, review this file first. Any deliberate deviation should be documented here before implementation.
